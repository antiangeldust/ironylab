# Папка для моделей

В репозиторий модели не входят — они большие и у каждой свой лицензионный режим.
Сюда (или в любое другое место) кладутся два файла:

1. **Модель эмбеддингов** для семантики — папка `sentence-transformers`,
   например `paraphrase-multilingual-MiniLM-L12-v2` (~470 МБ, скачивается
   автоматически при первом анализе, если в настройках указано её имя).

2. **Модель для локальной LLM** — файл `.gguf`, например
   `qwen2.5-1.5b-instruct-q4_k_m.gguf` (~1,1 ГБ).

Как скачать и подключить — в [INSTALL_RU.md](../INSTALL_RU.md), разделы 3 и 4.
Пути к моделям задаются в окне программы: **Настройки → Семантика** и
**Настройки → Локальная LLM**, либо одной командой:

```powershell
python configure_local_models.py
```
